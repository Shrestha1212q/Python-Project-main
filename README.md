 WeCare Store Application

The "WeCare Store: is a Python-based inventory and skincare management system. This application is designed to streamline vendor operations, manage product inventory, and handle customer purchase logic efficiently.

 Features
*   Inventory Management: Tracks product stock levels using external text file storage.
*   Automated Purchase Logic: Implements a "Buy Three Get One Free" discount policy.
*   Modular Design: Built with clear input/output handling.
*   Data Persistence:Maintains product data through read/write operations to local files.

 Technical Details
   Language: Python
   Core Logic: Inventory management without relying on advanced string formatting libraries, focusing on raw data handling and algorithmic logic.

 Usage
1. Clone the repository.
2. Run the main script to interact with the inventory menu.
3. Use the system to add, view, or purchase products.

 Project Context
Developed as part of a specialized project requiring specific inventory management logic and modular structure.
